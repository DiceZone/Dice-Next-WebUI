# 本地 UI 预览

运行 `npm run dev:preview`，打开 `http://127.0.0.1:5173/#/decks`、`#/settings`、`#/replies`、`#/commands` 或 `#/help`。

此模式使用真实页面组件和独立的内存 API，不代理后端，不连接机器人，不读取或写入业务文件。测试中的编辑、导入、删除和支持的配置修改只保留到服务退出。右下角显示预览标记；普通 `npm run dev` 和生产构建不包含这些样例。指令页的全部分类由预览样例填充，实际分类仍由后端返回的指令决定。

检查流程：

- 设置：切换六个栏目，编辑前缀后切页返回；用全局搜索定位其他栏目；重播指引检查跨栏目聚焦。
- 牌堆：搜索标题、作者、牌堆名；切换文件和条目；检查多行内容、隐藏牌堆和分页。
- 编辑：在条目与源码视图之间切换；尝试无效 JSON；关闭时确认未保存保护；保存后刷新内容。
- 导入：选择 `tests/fixtures/ui-deck.json`，确认后检查内容；再次选择同名文件检查覆盖确认。
- 下载：下载当前文件，检查元信息、权重、引用和换行。
- 回复：手机上检查规则卡片的触发词、回复和限制；宽屏检查表格。打开添加或编辑弹窗，检查宽屏高级选项展开、手机收起，并验证折叠后保存的概率与冷却值。
- 指令：横向滚动查看全部分类，修改 `.r` 文案并检查预览；其他分类仅有示例指令，不代表后端数据。
- 帮助：检查内置覆盖、自建文档保存、来源只读说明、手机布局、未保存确认和同名导入确认。
- 分别检查浅色、深色、桌面与手机布局。

`npm test` 包含牌堆结构校验和无损字段更新的回归测试。预览仅验证前端交互，不替代真实后端的集成验证。
